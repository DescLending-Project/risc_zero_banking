# Score Publisher - Hybrid Credit Score System

This is the main component with the fully integrated system for publishing the nested proof with a hybrid credit score on-chain.

## Directory Structure
```text
├── host/
│   ├── receipts/                   # Contains the 3 inner proofs as SNARK receipts
│   │   ├── tradfi_score.bin        # TradFi credit score proof
│   │   ├── account_receipt.bin     # DeFi account verification proof
│   │   └── alchemy_stateroot.bin   # Blockchain state root proof
│   └── src/                        # Publisher that interacts with blockchain and executes zkVM
├── lib/
│   └── core/                       # Libraries copied from root (required for Docker R0 container)
│       ├── score_calculation/      # Logic for hybrid credit score calculation
│       ├── defi_inputs_serializer/ # Custom serializer for DeFi inputs
│       └── merkle_verifier/        # Helper library for the serializer
├── methods/                        # zkVM code for verifying inner proofs and calculating scores
└── hybrid_credit_score.bin         # Example SNARK proof output
```
## Inner Proof Sources

The inner proof receipts in [`host/receipts/`](./host/receipts/) are generated by components in [`../risc0_proofs/`](../risc0_proofs/):
- **`tradfi_score.bin`** - Generated by [`tradfi_score_tlsn_proof/`](../risc0_proofs/tradfi_score_tlsn_proof/)
- **`defi_inputs_receipt.bin`** - Generated by [`defi_inputs_validation_proof/`](../risc0_proofs/defi_inputs_validation/)
- **`alchemy_stateroot.bin`** - Generated by [`stateroot_tlsn_proof/`](../risc0_proofs/stateroot_tlsn_proof/)

## On-Chain Output

The system publishes the following data structure on-chain:

```solidity
struct JournalData {
    uint64 score;                    // Final hybrid credit score
    string serverName;               // TradFi API server name (from tradfi_score_tlsn_proof proof)
    string stateRootProvider;        // Blockchain RPC provider (from stateroot_tlsn_proof proof)
    uint64 blockNumber;              // Block number of state root (from stateroot_tlsn_proof proof)
    bytes32 tradfiNullifier;         // Hashed user identifier (from tradfi_score_tlsn_proof proof)
    uint64 tradfiDateTimestamp;      // Timestamp of TradFi score fetch (from tradfi_score_tlsn_proof proof)
    address userAddress;             // Blockchain address (from defi_inputs_validation proof)
    address contractAddress;         // Adress (Lending Contract) from which DeFi data is fetched
    bytes32[] allNullifiers;         // Account nullifiers (from defi_inputs_validation proof)
}
```
# Prerequesites
* **Rust** 
* **RISC Zero toolchain**
* **Docker**
* **Anvil** 

## NOTE: It is important to always use RISC0_USE_DOCKER=1 to ensure the builds and runs are deterministic

# 1. Build the binaries
Build the Risc Zero binaries first in order to make sure you have the right ImageID
```bash
RISC0_USE_DOCKER=1 cargo build --release
```
# 2. Setup Anvil Environment

Deploy the required smart contracts located in the [`Solidity/`](../solidity) directory.
Note: Make sure your local Ethereum node (e.g., Hardhat or Anvil) is running and that the contract address and private key are correct.

# 3. Run locally with Anvil

To run with Bonsai export this before:
```bash
export BONSAI_API_KEY="<BONSAI_API_KEY>"
export BONSAI_API_URL="<BONSAI_API_URL>"
```
Coompute the credit score proof :
```bash
RISC0_USE_DOCKER=1 cargo run -p host --bin host --release -- \
  --tradfi-receipt-path host/receipts/tradfi_score.bin \
  --account-receipt-path host/receipts/valid_defi_inputs_receipt.bin \
  --stateroot-receipt-path host/receipts/alchemy_stateroot.bin \
  --chain-id 31337 \
  --rpc-url http://localhost:8545 \
  --contract 0x9fE46736679d2D9a65F0992F2272dE9f3c7fa6e0 \
  --eth-wallet-private-key 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80

```
The inner proof are supposed to be provided through the cli

# Extract ImageID

You can extract ImageIDs from the receipts:
```bash
cargo run -p host --bin extract_imageid --release -- host/receipts/alchemy_stateroot.bin
```
# Submit Proof of Credit Score to our Sepolia contract

You can also submit your proof to our Sepolia deployed contract: https://sepolia.etherscan.io/address/0xaa76acf6a50f94756eb451ee3c519432f527d59c

Export your Sepolia wallet private key and Alchemy (Sepolia) API key:
```shell
export ETH_WALLET_PRIVATE_KEY=""
export ALCHEMY_API_KEY=""
```
Then run:

```bash
RISC0_USE_DOCKER=1 cargo run -p host --bin host --release -- \
  --tradfi-receipt-path host/receipts/tradfi_score.bin \
  --account-receipt-path host/receipts/valid_defi_inputs_receipt.bin \
  --stateroot-receipt-path host/receipts/alchemy_stateroot.bin \
  --chain-id 11155111 \
  --rpc-url https://eth-sepolia.g.alchemy.com/v2/${ALCHEMY_API_KEY:?} \
  --contract 0xaa76ACf6a50f94756eB451Ee3c519432f527d59C \
  --eth-wallet-private-key ${ETH_WALLET_PRIVATE_KEY:?}
```
